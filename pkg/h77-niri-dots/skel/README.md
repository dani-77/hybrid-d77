## Keybinds

super + return / super + t -> terminal (foot)

super + space -> app launcher (Utumno)

super + d / super + tab -> overview

super + y -> wallpaper picker

super + alt + l -> lock screen

super + x -> power menu

super + q -> close window

super + f -> maximize column

super + shift + f -> fullscreen

super + shift + t -> toggle floating

super + 1..9 -> workspace 1..9

super + shift + / -> show all keybinds

super + shift + e -> quit niri

Print -> screenshot

## Tweaks

Keybinds live in ~/.config/niri/d77/binds.kdl; autostart programs,
keyboard layout and window rules in ~/.config/niri/config.kdl.
Wallpapers for the picker go in ~/Wallpaper.

Utumno can also be driven from a terminal with qsd77, e.g.
`qsd77 launcher -c utumno` (see `qsd77 --help`).

Have fun!
